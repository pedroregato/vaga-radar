# n8n/workflows/

Fluxos exportados do N8N (marco M3 em diante).

Antes de cada commit:
1. Exporte o fluxo pelo menu do N8N (Download), **sem credenciais**.
2. Revise o JSON: não pode haver tokens, chaves, e-mails pessoais ou IDs de credencial com dados sensíveis.
3. Salve como `vaga_radar.json` e descreva a mudança no commit.
