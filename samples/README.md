# samples/

E-mails de alerta de vaga **anonimizados**, usados para calibrar o prompt (marco M2).

Regras:
- Antes de copiar um e-mail para cá, troque nomes de pessoas, e-mails, telefones e IDs de rastreamento por marcadores (`<RECRUTADOR>`, `<EMAIL>`).
- Rascunhos não anonimizados ficam em `samples/raw/`, que está no `.gitignore`.
- `labels.csv` guarda a faixa de nota esperada para cada amostra.
